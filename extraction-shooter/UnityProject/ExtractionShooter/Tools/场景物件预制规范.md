# 通用场景物件预制规范

本规范适用于餐厅、战斗、地图装饰以及后续模块的树、草、家具和其他 2D 图片物件。目标是让美术按普通二维平面摆放，编辑器里的层级和运行时保持同一套接地点、尺寸和排序规则。

## 美术资源与目录

- 原始 PNG/Sprite 由美术放在自己负责的素材目录，保留像素、透明留白和原始比例。工具不会复制、改名、移动或重采样源图片。
- Unity 的 PPU 是“多少图片像素对应一个 Sprite 单位”。美术不需要为了适配镜头改图或计算缩放；资源按项目导入预设使用原始像素比例，工具读取 Sprite 尺寸建立预制体。
- 程序生成的预制体统一放在 `Assets/Modules/GeneratedPrefabs/` 下，并按归属自动分目录：
  - `GeneratedPrefabs/Restaurant/<分类>/`：餐厅专用物件；
  - `GeneratedPrefabs/Shared/Vegetation/`：可跨模块复用的树、草、石头等；
  - `GeneratedPrefabs/<模块>/<分类>/`：其他模块专用物件。
- 已有模块专用预制体可以继续保留在模块自己的 `Prefabs` 目录。目录位置不会改变预制体的运行规则，禁止为了适配镜头手动复制 `_XY`、`_XZ` 版本。

## 创建新预制体

1. 在 Project 窗口选中导入的 PNG 或 Sprite。
2. 右键选择 **场景物件 → 创建场景物件预制体**。
3. 选择“统一 Prefab 目录”。工具会按素材路径推断模块和分类并创建目录；选择“与源资源同目录”只用于明确要求与源文件并列的模块。
4. 选择是否“跟随镜头”。树、草等始终正对玩家的装饰通常选择跟随镜头；需要保留场景透视纵深的地板、地毯、餐厅家具和整块背景选择保持世界平面。餐厅统一选择保持世界平面。
5. 创建完成后直接把生成的预制体拖入对应 World，在二维平面移动根节点。不要缩放或旋转 `VisualRoot`、`Art`、`ContactRoot`。

需要正面显示的单个树、草或装饰物才启用 `CameraFacingVisual`。餐厅不使用跟随镜头组件，美术仍按二维平面摆放，运行时由透视镜头自然产生 2.5D 纵深。逻辑根、碰撞和功能锚点不会被视觉规则旋转或移动。

预制体结构固定为：

```text
物件根节点（布局与接地点）
├─ VisualRoot（可选 CameraFacingVisual）
│  └─ Art（SpriteRenderer、PlanarSprite）
├─ ContactRoot（图片接地点）
├─ PhysicsRoot（碰撞与刚体）
└─ AnchorsRoot（交互、业务锚点）
```

根节点、`VisualRoot` 和 `Art` 的缩放都保持 `(1,1,1)`。`PlacementItem` 的源图尺寸模式记录 Sprite 的导入宽高和接地点；换图只替换 `Art` 的 Sprite，再执行“应用图片配置”，不通过手动拉伸图片补偿镜头。镜头远近由镜头配置调整。

## 旧预制体与通用树草模板

- 选中旧的裸 `SpriteRenderer` 或包含多个标准物件的场景预制体，右键 **场景物件 → 设置为跟随镜头**，工具会补齐标准层级，并对其中全部 `PlacementItem` 的 `VisualRoot` 设置跟随；不会因其标记为 Ground 而跳过，也不会修改原 Sprite 与原始尺寸。
- 组件挂在 `VisualRoot`，所以运行时 `Art` 的 Local Rotation 仍显示为 0；应查看 `Art` 的 World Rotation 或父级 `VisualRoot`。在当前 45° 餐厅镜头下，世界角度应为 X=315°，与手动把 `Art` 设为 X=-45° 的画面完全一致。
- 需要 2.5D 世界平面显示时选择 **取消跟随镜头**；工具移除组件并把视觉恢复到美术二维编排平面，不动逻辑根、碰撞和锚点。餐厅的地板、桌椅、灶台、柜子、冰箱和柜台都使用此模式。
- `Assets/Environment/Vegetation/Prototype/Prefabs/Vegetation_Single_Tree.prefab` 与 `Vegetation_Single_Grass.prefab` 已按同一规则转换，可作为通用树草模板。后续新树、新草直接从源图片右键创建，不再手工复制这两个文件。
- 同一外观需要多个方向时交付方向图或预制体变体；不要旋转整张图片伪造不存在的侧面。

## 提交前检查

在 Unity 中选中预制体执行 **Tools → Modules → Placement → Validate Selected**（或在模块验收窗口执行标准检查）。必须确认：标准组件引用完整、接地点落在图片底部、根节点缩放为 1、视觉分支没有碰撞、排序绑定 Contact、没有场景相机引用。通过后再提交布局和预制体。
