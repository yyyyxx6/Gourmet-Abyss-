# 装饰笔刷 · 美术使用说明

入口：**场景 → 装饰笔刷**。

## 文件夹

| 内容 | 目录 | 用途 |
|---|---|---|
| 共享笔刷预设 | `Assets/ArtWorkspace/Editor/BrushPresets` | 保存资源组合和参数，可提交给团队；保存预设时默认打开这里 |
| 本地测试场景 | `Assets/ArtWorkspace/LocalTests` | 放试刷用的场景副本，不提交、不用于发布 |

通过 **场景 → 笔刷工作区** 定位目录。正式场景和资源继续放原有制作目录。

## 开始使用

1. 打开要编辑的场景，保持非运行状态；只想试刷时，把场景另存到本地测试目录。
2. 点击“创建装饰组”。按场景地面选择 XY / XZ；“放在哪个节点下”留空则建在场景根目录，餐厅模块内摆放时拖入模块节点。
3. 从 Project 拖入装饰预制体并勾选，可一次加入多个。
4. 点击“开始绘制”，在 **Scene** 中操作。完成后按 **Esc** 退出，**Ctrl+S** 保存场景。

## 操作说明

| 操作 | 作用 |
|---|---|
| 连续绘制 | 按住左键拖动，沿途刷出装饰；停住鼠标不会持续堆叠 |
| 单个放置 | 每次点击放一个装饰 |
| 擦除 / Shift＋左键拖动 | 擦除当前组刷出的装饰；保留手动摆放及其他组的物件 |
| 勾选资源 / 全选 | 决定哪些资源参与绘制；勾选多个时随机混合 |
| 出现权重 | 数值越大，该资源出现的概率越高 |
| 资源右侧 × | 从笔刷列表移除，不删除项目资源 |
| 半径 / `[`、`]` | 调整绘制和擦除的范围 |
| 密度 | 调整连续绘制的数量，越大越密 |
| 最小间距 | 控制当前组笔刷物件之间的距离，优先于密度；不等同于碰撞避让 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做整笔绘制或擦除 |
| 使用场景中选中的组 | 先选中已有装饰组或其内部物件，再点击此按钮继续编辑 |
| 另建一个装饰组 | 将接下来绘制的物件分组管理 |
| 定位 / 点击资源名称 | 分别定位当前装饰组 / 源预制体 |
| 另存为预设 / 更新当前预设 | 保存新的资源组合和参数 / 覆盖当前预设 |
| 载入预设 | 将预设文件拖入“笔刷预设”栏，恢复资源组合和参数 |
| Esc / 结束绘制 | 退出笔刷，恢复正常场景编辑 |

当前支持平面摆放，保留源预制体尺寸和朝向。刷不出来时，先看窗口提示，再检查平面、高度、镜头角度和最小间距。

跟随镜头的装饰在 Scene 自由视图中按游戏朝向预览。检查最终构图时，在 Scene 的 **场景镜头** 面板选择 **游戏镜头**；**2D 布局**用于平面排布。

普通地面图片（包括旧场景）需设置一次：**Sprite Renderer → Additional Settings → Sorting Layer → SceneGround**，然后保存场景。注意是 Sorting Layer，不是 Inspector 顶部的 Layer。

项目提供的标准地面预制体会自动设置。笔刷使用的树、道具预制体保持 **Default**，前后遮挡自动处理，无需手动改 Order in Layer。
