# 植被美术交接说明

## 命名

`<类别>_<风格/品种>_<变体>_<LOD>`

例：`Tree_Dead_A_LOD0`、`Grass_Desert_Dry_LOD1`。

## 材质和贴图

- 贴图放在项目统一的植被贴图目录，材质放在对应品种子目录。
- Alpha 裁切植被使用同一套 Cutout 阈值；透明混合只用于确有需要的薄片。
- 主色、风摆参数优先在材质中调，预制体只保存摆放和碰撞差异。

## 性能基线

- 草的单个预制体尽量控制在 2 个材质以内。
- 大面积铺设优先使用 GPU Instancing；避免每株草独立脚本。
- 远景树必须提供简化模型或 Billboard，避免整片都使用高模。
- 触发器碰撞体只用于交互草；纯装饰草不加碰撞。
